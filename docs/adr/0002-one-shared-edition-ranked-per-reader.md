# One shared Edition per run, ranked separately for each Reader

Each run gathers a single Edition that covers every Topic any Reader follows. Each Reader's Brief is a filtered, ranked view of that Edition. We considered a separate gathering run per Reader (more tailored, but cost and run time grow with every Reader) and a hybrid with personal extras. We rejected both so that adding a Reader stays almost free. Personalisation comes from ranking (scoring from the Interest Profile and Reactions, with Claude picking each Reader's lead stories), not from gathering.

## Consequences

- A Topic only one Reader follows still costs a full gathering slot. That's why Readers have a cap on how many Topics they can create, and why Topics nobody follows are dropped.
- Item facts, sources and link checks are shared. Only ranking and "why this matters to you" are per Reader.
